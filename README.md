# CREST Urban Workshop 2026

Static one-page site for the workshop, served via GitHub Pages.

## Files
- `index.html` — the page. Fill in the placeholders marked `<!-- EDIT -->`.
- `assets/` — put `workshop.jpg` (image) and `programme.pdf` (programme) here.
- `.nojekyll` — tells GitHub Pages to serve the raw HTML without running Jekyll.

## Publishing
See the chat instructions, or in short:
1. Create a repo named `crest_urban_workshop2026.github.io` under an account/org named `crest_urban_workshop2026` — OR use a normal repo + project pages (simpler, see notes).
2. Push these files to the default branch.
3. Settings → Pages → Source: deploy from branch → root.
